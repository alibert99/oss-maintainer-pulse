# Roadmap

Maintainer Pulse starts with deterministic GitHub issue and pull request reports.
The near-term roadmap keeps the tool useful without requiring hosted services.

## Planned

- Duplicate issue candidate detection from titles and labels.
- Optional AI-assisted summaries that run only when a maintainer explicitly
  provides an API key.
- Configurable label groups for projects that use custom priority and review
  labels.
- More real-world reports and maintainer feedback notes from public repositories.

## Completed

- Real-world example reports from public repositories.
- CSV output for spreadsheet-based triage.
- Release blocker grouping by GitHub milestone in Markdown reports.

## Non-Goals

- Replacing human maintainer judgment.
- Writing to GitHub by default.
- Requiring a hosted backend.
