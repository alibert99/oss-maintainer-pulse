# Support

Maintainer Pulse is maintained through GitHub issues.

## Questions

Open a discussion-style issue if you need help deciding how to run the CLI,
configure the GitHub Action, or interpret a generated report.

## Bugs

Use the bug report template and include:

- The command or GitHub Action configuration.
- The package or release version.
- A small input fixture when the report output is wrong.
- The expected queue or metric result.

## Feature Requests

Use the feature request template and describe the maintainer workflow the change
would improve. Features that keep the tool read-only, deterministic, and easy to
audit are the best fit.
